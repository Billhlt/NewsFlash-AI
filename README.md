# NewsFlash-AI
该项目是一个专门用于快速看新闻的ai助理，会在一个界面内同时显示可多达上百个新闻内容的摘要，并可自动对复杂词汇进行解释+一键标亮新闻一键将标亮新闻记入本地txt，ob等文件中。This AI assistant displays summaries of up to 100 news items on one page, automatically explains complex words, and lets you highlight and save selected content to local files (e.g., .txt, Obsidian) with one click.
